# KET 词汇连线课堂

[进入在线课堂](https://ket-word-link-classroom.lapafahagafa.chatgpt.site/)

本仓库提供 GitHub Pages 的公开入口，自动跳转到在线课堂。完整练习应用和数据库仍运行在现有在线服务上，本仓库不包含学生成绩或数据库凭据。

## 课堂功能

- 28 个单元，按教材区分基础单词与核心词汇。
- 填写姓名后选单元，中英文连线、图片、正确反馈和彩带特效。
- 在线数据库保存进度与首次成绩，共享排行榜。
- 每个单词首次连线锁定，重复练习不改首次成绩。
- 仅填写姓名不能验证真实身份，无法完全防止冒用姓名或换名刷分。

## 开启 GitHub Pages

仓库 Settings → Pages → Build and deployment：

1. Source 选择 Deploy from a branch。
2. Branch 选择 main，目录选择 / (root)。
3. 点击 Save，等待 GitHub 显示发布完成及访问链接。

## 记录存储

练习页面需要联网；成绩保存在在线课堂数据库中，不保存在 GitHub 仓库里。离线单机版已有的本机记录不会自动迁移到在线课堂。
